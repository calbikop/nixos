# NixOS

Declarative NixOS configuration for MSI Thin GF63 12VF (i7-12650H + RTX 4060) running Ryoku (Hyprland + Quickshell).

Current setup includes:
- Ryoku desktop environment (Hyprland as compositor, Quickshell UI)
- Custom hardware tuning and audio configuration
- Freebuff CLI packaged via npm build
- Sonora music client (via flake input)
- Aria2 daemon, Cloudflare WARP, ydotool/uinput automation support
